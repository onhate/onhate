# WakaTime README Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Run a dependency-free README generator in GitHub Actions each day.

**Architecture:** One Python script reads WakaTime with a personal OAuth token. It builds Markdown from allowed fields and replaces the existing section only after every required request succeeds.

**Tech Stack:** Python standard library, unittest, GitHub Actions.

**Spec:** ../../wakatime-research.md, approved in the chat on 2026-10-29.

## Global Constraints

- Work in the current main checkout, as the user instructed. Do not create a worktree.
- GitHub servers run the generator. The user's machine need not stay on.
- Show summary and AI data. Omit project names and machine details.
- Keep the greeting, badge, and section markers.
- Use Bearer authentication and `WAKATIME_ACCESS_TOKEN`. Never print the token or raw responses.
- Keep the last README when data cannot be fetched. Use bounded retries.
- No added Python packages, services, or databases.

## Review Focus

- An error or stale response must not erase existing content.
- Missing optional measurements must not become zeroes.
- Untrusted text must not inject Markdown or HTML.
- A change outside the generated section must remain intact.
- The workflow must validate code without a credential and must not race another update.
